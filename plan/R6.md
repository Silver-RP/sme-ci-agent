# R6 (auto-dev run 6): Dashboard Next.js: skeleton bằng mock, đọc SSE, ghép API thật

**Phục vụ plugin: P4/P5**: mốc đầu tiên có frontend (Node/yarn) chạy bằng chế độ B; cổng verify thêm bước cho `dashboard/`. Các task vẫn phải đạt DoD của TASKS.md (T-016, T-026), ADR-005 (dashboard đơn giản: bảng + timeline trace, ít biểu đồ) và ADR-003 (`docs/schema/events.json` là hợp đồng, không sửa).

## Mục tiêu
- Dashboard xem được một run scenario 1 từ đầu đến cuối: bảng anomaly, timeline trace, trả lời câu hỏi (Ask), duyệt/từ chối đề xuất và rollback.
- Chạy được với fixture (không cần backend) và với API thật của R5 (`backend/api/`).

## Phạm vi
- Trong: thư mục `dashboard/` (Next.js, App Router, TypeScript, yarn); kiểu dữ liệu sinh từ hoặc viết theo `events.json`; fixture trace; client SSE; gọi `POST /runs`, `/answer`, `/approval`.
- Ngoài: biểu đồ (PLAN mục 7: cắt đầu tiên), đăng nhập, triển khai, đổi `events.json` hay API backend (cần thì ghi "Đề xuất chờ duyệt").

## Quy ước chung
- Package manager: yarn (TASKS T-016). Không thêm thư viện UI lớn; CSS đơn giản (CSS Modules hoặc Tailwind nếu create-next-app đề xuất mặc định).
- Test: Vitest + Testing Library cho component và logic; không gọi mạng thật trong test (SSE và fetch được mock hoặc phát lại fixture).
- Ba lệnh phải chạy được trong `dashboard/`: `yarn lint`, `yarn test` (chạy một lần, không watch), `yarn build`.
- URL backend đọc từ biến môi trường `NEXT_PUBLIC_API_URL` (mặc định `http://localhost:8000`); không hard-code.
- Thiếu Node.js hoặc yarn trên máy: dừng, ghi BLOCKED và báo, không tự cài công cụ hệ thống.
- Python không đổi; `python3 .autodev/verify.py` vẫn phải sạch.

## Tiêu chí chấp nhận cấp mốc
1. `python3 .autodev/verify.py` sạch so với baseline (bước `dashboard` chạy lint + test + build).
